## Items
- Type :: the type of stoma formed (e.g. end or loop colostomy, ileostomy) :: text
- Site marked :: the stoma site was marked preoperatively, or its absence :: presence
- Location :: the location of the stoma on the abdominal wall :: text
- Matured :: the stoma was matured / spouted, or its absence :: presence
- Bowel viability :: the viability of the bowel forming the stoma :: text
- Intended duration :: whether the stoma is intended to be temporary or permanent :: text
