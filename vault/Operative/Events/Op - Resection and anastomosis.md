## Items
- Segment resected :: which segment was resected and its length :: text
- Margins :: the resection margins :: text
- Bowel viability :: the viability of both cut ends before anastomosis (colour, peristalsis, mesenteric pulsation, bleeding from the cut edge, sheen) :: text
- Tension-free :: the anastomosis was fashioned tension-free, or its absence :: presence
- Technique :: whether the anastomosis was hand-sewn or stapled :: text
- Configuration :: the anastomosis configuration, such as end-to-end, side-to-side or end-to-side :: text
- Layers and suture :: the number of layers and the suture or staple material used :: text
- Leak test :: a leak test was performed, or its absence :: presence
- Mesenteric defect closed :: the mesenteric defect was closed, or its absence :: presence
- Abdomen irrigated :: the abdomen was irrigated before closure, or its absence :: presence
- Pelvis and gutters checked :: the pelvis and paracolic gutters were checked before closure, or its absence :: presence
