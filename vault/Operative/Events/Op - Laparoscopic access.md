## Items
- Entry technique :: the entry technique used (e.g. Veress needle, Hasson open, optical trocar) :: text
- Number of ports :: the number of ports used :: number ports
- Port sizes and sites :: the size and site of each port :: text
- Insufflation pressure :: the insufflation pressure used :: text
- Port sites inspected :: the port sites were inspected for hemostasis on exit, or their absence :: presence
- Fascial closure of large ports :: fascial closure was performed for ports of 10mm or larger, or its absence :: presence
