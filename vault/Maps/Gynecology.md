# Gynecology

Map of content for the Gynecology bundles.

## History

- [[Gyn - Abnormal bleeding]]
    - → [[Menstrual history]]: Abnormal bleeding is assessed against the baseline menstrual history
    - → [[Pain]]: The sheet's gynecological pain section maps to the general pain analysis
    - → [[Heme - Bleeding tendency]]: Menorrhagia can be the presenting feature of a systemic bleeding disorder
- [[Gyn - Ectopic pregnancy]]
    - → [[Gyn - Pelvic mass]]: An ectopic pregnancy can present as a pelvic mass detailed in that bundle
    - → [[Gyn - Previous cesarean and obstetric history]]: An ectopic pregnancy is part of the full obstetric history
- [[Gyn - Previous cesarean and obstetric history]]
    - → [[Gyn - Pregnancy]]: The obstetric history is assessed alongside any current pregnancy in that bundle
    - → [[Heme - Bleeding tendency]]: Postpartum hemorrhage can be the presenting feature of an underlying bleeding disorder
- [[Gyn - Pelvic mass]]
    - → [[Urinary symptoms]]: A pelvic mass can compress the bladder or urethra
    - → [[Swelling - lump]]: A pelvic mass is analyzed using the same characteristics as any other lump
    - → [[Edema - limb swelling]]: A large pelvic mass can compress the pelvic veins
    - → [[Jaundice]]: The sheet lists liver metastasis with jaundice as a consequence of the mass
    - → [[Heme - Blood disorder]]: A large pelvic mass can cause anemia from chronic blood loss
- [[Gyn - Pregnancy]]
    - → [[Gyn - Previous cesarean and obstetric history]]: Current pregnancy is assessed alongside the full obstetric history in that bundle
    - → [[Menstrual history]]: Pregnancy dating is cross-checked against the baseline menstrual history
- [[Menstrual history]]
    - → [[Gyn - Abnormal bleeding]]: A positive screen opens the abnormal bleeding bundle for pattern and amount
    - → [[Gyn - Pelvic mass]]: A positive screen opens the pelvic mass bundle for compressive and metastatic features
