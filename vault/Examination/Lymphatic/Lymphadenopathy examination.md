## Items
- Groups involved :: which lymph node groups are enlarged, such as cervical, axillary, supraclavicular or inguinal :: text
- Number :: the number of enlarged nodes :: text
- Matting / fixity :: whether the nodes are matted or fixed, or their absence :: presence
- Organomegaly :: hepatomegaly or splenomegaly, or their absence :: presence
- Limb edema :: edema of the ipsilateral limb, or its absence :: presence
- D'Espine sign :: D'Espine sign (dullness over T4 on percussion, or a tubular breath sound on auscultation), or its absence :: presence

## Related
- [[Swelling examination]] :: Node examination :: the size, shape, surface, consistency, tenderness or mobility of the enlarged nodes, or their absence :: An enlarged lymph node is examined using the same characteristics as any other swelling
