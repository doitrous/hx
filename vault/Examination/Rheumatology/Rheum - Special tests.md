## Items
- Hand / wrist tests :: the prayer sign, reversed prayer sign, Phalen's test or Tinel's test, or their result :: text
- Knee tests :: the bulge test, patellar tap, fluctuation test or a medial/lateral stress test, or their result :: text
- Spine tests :: the Schober test or a modified Schober test, or its result :: text
- Sacroiliac tests :: pelvic springing, the FABER test, sacroiliac pressure test or Gaenslen's test, or their result :: text
- Sciatic / nerve root tests :: sciatic nerve stretch testing or a straight leg raise (Lasegue) test, or its result :: text
- Meningeal signs :: Kernig's sign or Brudzinski's sign, or their absence :: presence
