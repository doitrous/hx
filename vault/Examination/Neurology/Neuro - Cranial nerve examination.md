## Items
- Olfactory :: sense of smell (cranial nerve I), or an abnormality of it :: text
- Optic :: visual acuity, color vision, visual fields or the light and accommodation reflexes (cranial nerve II) :: text
- Eye movements :: ptosis, pupil size, eye movements, squint or nystagmus (cranial nerves III, IV and VI), or their absence :: text
- Trigeminal :: facial sensation, jaw movement or the corneal reflex (cranial nerve V) :: text
- Facial :: facial inspection, taste or facial movements (cranial nerve VII), or their absence :: text
- Hearing / balance :: hearing or balance testing (cranial nerve VIII) :: text
- Palate / gag reflex :: palatal movement, the gag reflex or uvula position (cranial nerves IX and X) :: text
- Shoulder / neck power :: sternomastoid or trapezius power (cranial nerve XI) :: text
- Tongue :: tongue protrusion or deviation (cranial nerve XII), or its absence :: presence
