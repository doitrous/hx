## Items
- Site :: the site of the stone, such as renal, ureteric or bladder :: text
- Number of episodes :: the number of previous episodes or colic attacks :: text
- Last episode :: the date of the last episode :: text
- Treatment :: how it was treated, such as lithotripsy, ureteroscopy or surgery :: text
- Stone passed :: spontaneous passage of a stone, or its absence :: presence
- Residual stones :: known residual stones, or their absence :: presence
- Recurrent UTI :: recurrent urinary tract infection associated with the stones, or its absence :: presence
