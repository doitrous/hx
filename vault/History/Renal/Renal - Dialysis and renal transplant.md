## Items
- Modality :: whether the patient is on hemodialysis, peritoneal dialysis, or has a transplant :: text
- Access or site :: the vascular access (fistula, graft or catheter) or dialysis site :: text
- Schedule :: the dialysis schedule, such as sessions per week :: text
- Last session :: the date of the last dialysis session :: text
- Dry weight :: the dry weight, or that none is stated :: text
- Residual urine output :: residual urine output, or its absence :: presence
- Transplant details :: the transplant date and donor type, if applicable :: text
- Immunosuppression :: immunosuppressive medication taken :: text
