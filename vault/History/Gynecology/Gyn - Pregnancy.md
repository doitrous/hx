## Items
- Gestational age :: the gestational age or LMP-based dating :: text
- Gravida / para :: gravida and para, such as G2P1 :: text
- LMP :: the last menstrual period (LMP) date :: text
- EDD :: the expected date of delivery (EDD) :: text
- Antenatal care :: antenatal care attendance, or its absence :: presence
- Antenatal problems :: a documented antenatal problem such as gestational diabetes or pre-eclampsia, or their absence :: presence
- Fetal movements :: fetal movements, or their absence :: presence
