## Items
- Number of pregnancies :: the total number of pregnancies (gravida) :: text
- Number of deliveries :: the number of deliveries and their mode, vaginal or cesarean :: text
- Number of cesarean sections :: the number of previous cesarean sections and their indication :: text
- Complications :: a complication of a previous pregnancy or delivery, or its absence :: presence
- Miscarriage :: a previous miscarriage, or its absence :: presence
- Postpartum hemorrhage :: a previous postpartum hemorrhage, or its absence :: presence
