## Items
- Type :: the type of anemia, such as iron deficiency or megaloblastic :: text
- Cause :: a known cause, such as chronic blood loss, dietary deficiency or chronic disease :: text
- Latest hemoglobin :: a hemoglobin value, or that none is available :: number g/dL
- Treatment :: iron, vitamin B12, folate or another treatment taken :: text
- Transfusion history :: a previous blood transfusion for the anemia, or its absence :: presence
- Symptoms :: fatigue, dyspnea or dizziness attributed to the anemia, or their absence :: presence
