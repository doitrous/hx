## Items
- Onset :: when heart failure was diagnosed :: text
- Etiology :: the cause of the heart failure, such as ischemic, hypertensive or valvular :: text
- Exercise tolerance :: the functional class or exercise tolerance :: text
- Ejection fraction :: a recent ejection fraction or echocardiogram result :: text
- Current medications :: diuretics, ACE inhibitors, beta blockers or other heart failure medication :: text
- Fluid / weight monitoring :: fluid restriction or daily weight monitoring, or their absence :: presence
- Hospital admissions :: a previous hospital admission for heart failure decompensation, or its absence :: presence
- Cardiology follow-up :: ongoing cardiology follow-up :: text
