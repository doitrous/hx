## Items
- Date of last event :: when the last myocardial infarction or acute coronary syndrome occurred :: text
- Intervention :: a coronary intervention such as a stent type or bypass surgery, and when it was done :: text
- Current angina :: current angina or its absence :: presence
- Exercise tolerance :: the exercise tolerance or level of exertion that brings on symptoms :: text
- Antiplatelet / anticoagulant drugs :: aspirin, clopidogrel, ticagrelor or an anticoagulant, or their absence :: presence
- Last echo / ejection fraction :: a recent echocardiogram result or ejection fraction :: text
- Cardiology follow-up :: ongoing cardiology follow-up :: text
- Risk factors :: cardiac risk factors such as smoking, diabetes, hypertension or dyslipidemia :: text
